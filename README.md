## Featured Projects

### 🛍️ Itza Beauty Shop — E-commerce (client project)
Full e-commerce platform for a real client, in production. Catalog with variants, reviews, cart, checkout, customer accounts and a 5-module admin panel. Integrations: Wompi (cards, PSE, Nequi), Alegra (DIAN e-invoicing) and Coordinadora (shipping).

**Stack:** Next.js · TypeScript · Zustand · TanStack Query · Django · DRF · Celery · Redis · PostgreSQL · Cloudinary  
**→ [Live App](https://itza-beauty-shop.vercel.app)** · *Private repository (client project)*

### 🥋 Budokan SKIF — Karate Dojo Management
Management platform for a real karate dojo, in production. Handles students, attendance tracking, belt progression, payment records and inventory.

**Stack:** React · Node.js/Express · PostgreSQL · Prisma  
**Testing:** Jest — 26 tests covering auth flows, student validation and API endpoints  
**→ [Live App](https://kensho.veridisdev.com) · [Repository](https://github.com/dacq7/kensho)**

**→ [Live App](https://idoneo-2210-plum.vercel.app) · [Repository](https://github.com/dacq7/idoneo-2210)**

## Architecture approach

- **Separation of concerns** — clean split between frontend, backend and database layers
- **Role-based access control** — implemented in my business apps
- **Schema validation** — Pydantic (Python) and Zod (TypeScript) in my business apps
- **Environment-based config** — no secrets in code, `.env` across all environments
- **Auto-deploy on Vercel/Railway** — every push to main goes live
